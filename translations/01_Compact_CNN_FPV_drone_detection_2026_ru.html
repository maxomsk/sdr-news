Компактные свёрточные нейронные сети для системы обнаружения БПЛА на основе ИИ

Оригинальное название: Compact convolutional neural networks for AI-based drone detection system

Авторы: Gábor Farkas, Gábor Fazekas, Patrik Karakai, András Németh, Gábor Farkas

Аффилиации: 1 — кафедра электронной войны, Университет государственной службы имени Людовика, Будапешт, Венгрия; 2 — факультет информатики, Университет Этвёша Лоранда, Будапешт, Венгрия

Источник: arXiv:2607.16455 (cs.LG), объявлено 17 июля 2026 г.

Перевод по аннотации (полный текст недоступен): метод, результаты и выводы — по данным аннотации.

АННОТАЦИЯ

Рост применения FPV-дронов в современных конфликтах требует компактных и надёжных систем обнаружения, работающих в сложной электромагнитной обстановке. Такие дроны непрерывно передают видеосигнал через бортовые видеопередатчики, создавая радиочастотные излучения, которые можно использовать для раннего обнаружения. Работа исследует применение лёгких свёрточных нейронных сетей (CNN) для автоматического обнаружения сигналов дронов, захваченных платформой радиоэлектронной борьбы на основе программно-определяемого радио (SDR). Отсчёты преобразуются в растровые изображения временной области — вычислительно эффективное представление, пригодное для встраиваемых систем. Несколько собственных архитектур моделей спроектированы и сопоставлены по точности, размеру модели и скорости инференса на наборе из примерно 40 000 размеченных изображений. Помимо офлайн-тестирования, модели интегрированы в тракт обработки сигналов GNU Radio для оценки в реальном времени. Результаты показывают, что компактные модели достигают высокой точности обнаружения при низких вычислительных требованиях, что делает их пригодными для встраиваемого радиочастотного мониторинга. По сравнению с существующими спектрограммными методами РЧ-обнаружения предложенный подход устраняет частотную предобработку и даёт сопоставимую точность при существенно меньших вычислительных затратах.

Ключевые слова: обнаружение БПЛА; FPV-дроны; свёрточные нейронные сети; программно-определяемое радио; GNU Radio; встраиваемые системы.

МЕТОД И ДАННЫЕ

  • Задача — автоматическое обнаружение сигналов FPV-дронов по РЧ-излучениям их видеопередатчиков, захватываемым SDR-платформой РЭБ.
  • Вход — растровые изображения временной области, полученные из отсчётов сигнала; частотная предобработка (спектрограммы) не используется.
  • Набор — примерно 40 000 размеченных изображений.
  • Спроектировано несколько собственных CNN-архитектур; сравнение по точности, размеру модели и скорости инференса.
  • Офлайн-бенчмаркинг дополнен интеграцией моделей в тракт GNU Radio для оценки в реальном времени.

РЕЗУЛЬТАТЫ

  • Компактные модели обеспечивают высокую точность обнаружения при низких вычислительных требованиях.
  • По сравнению с существующими спектрограммными РЧ-методами подход не требует частотной предобработки и достигает сопоставимой точности при существенно меньших вычислительных затратах.
  • Модели пригодны для встраиваемого радиочастотного мониторинга.
  • Конкретные метрики по отдельным архитектурам в аннотации не приводятся (полный текст недоступен).

ВЫВОДЫ

Лёгкие CNN по растровым представлениям временной области позволяют обнаруживать РЧ-сигналы FPV-дронов без частотной предобработки и при низких вычислительных требованиях, что делает подход перспективным для встраиваемых систем радиочастотного мониторинга. Ограничение реферата: он опирается только на аннотацию — постатейные метрики, размеры моделей и детали эксперимента в ней не раскрыты.
